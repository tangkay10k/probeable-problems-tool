# Probeable Problems Web Tool
Developed for UoA Part IV Project [#123](https://part4project.foe.auckland.ac.nz/home/project/detail/5793/) in order to teach students the critical skill of requirements elicitation by delivering problems with deliberately vague statements and a mechanism for students to clarify requirements in natural language. 

We deployed the tool in an introductory programming course of nearly 1000 students and research their exploration of the problem space in natural language as compared to code fragments.

Check it out @ [probeableproblems.online](https://probeableproblems.online/)

# Tech Stack
Built with Java Spring Boot, MongoDB, Node.js (React). Deployment using GCP.
